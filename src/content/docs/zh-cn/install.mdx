Browy 由两部分组成：

1. **浏览器扩展**：Chromium 侧边栏加 DevTools 面板。
2. **本地原生消息主机**：一个运行在你机器上的小型 Node.js 辅助进程，
   负责和 GitHub Copilot 通信。

先从 Chrome Web Store 安装扩展，然后运行一行命令安装本地主机。

<Aside type="tip" title="中国大陆开发者请先看这里">
GitHub Releases 和 Copilot 的访问情况和你所处的网络有关。如果安装脚本
卡住或者出现 TLS 错误，参考[中国开发者指南](/zh-cn/china-setup/)里的
镜像方案。
</Aside>

## 第一步：安装扩展

<LinkCard
  title="把 Browy 添加到 Chrome / Edge / Brave"
  href="https://chromewebstore.google.com/detail/iondecjdokngnlkfpipgolgkfegpmjca"
  description="一键安装。同一个商店页面覆盖 Chrome、Edge 和 Brave。"
/>

把 Browy 的工具栏图标固定到工具栏，方便随时打开侧边栏。

<Aside type="tip" title="✓ 确认">
点击 Browy 工具栏图标。侧边栏会打开并提示你安装后端，同时给出适合你操作系统的安装命令和一个复制按钮。这就是第二步。
</Aside>

<Aside type="tip" title="想用未打包方式加载？">
下面的本地主机安装脚本会同时把扩展的未打包版本放到
`%USERPROFILE%\Downloads\Browy-Extension\`（Windows）或
`~/Downloads/Browy-Extension/`（macOS / Linux）。打开
`chrome://extensions/`，开启**开发者模式**，点击**加载已解压的扩展程序**，
选择那个目录。本地主机已经同时预批准了 Web Store 版本和未打包版本的扩展 ID，
你可以在两者之间随意切换。
</Aside>

## 第二步：安装本地原生消息主机

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

打开 PowerShell 运行：

```powershell
irm https://github.com/BrowyHQ/browy/releases/latest/download/install.ps1 | iex
```

安装脚本会：

<Steps>
1. 下载最新 Browy 发行包（约 80 MB）
2. 把本地主机安装到 `%LOCALAPPDATA%\Browy\app\`
3. 在 Chrome / Edge / Brave 注册 `com.browy.host`（同时预批准 Web Store 和未打包扩展 ID）
4. 把扩展的未打包版本放到 `%USERPROFILE%\Downloads\Browy-Extension\`
</Steps>

<Aside type="tip" title="✓ 确认">
回到侧边栏。几秒钟内它会自己检测到后端并进入聊天界面（如果没有，关掉侧边栏再重新打开）。还是不行？确认主机已经装好：

```powershell
& "$env:LOCALAPPDATA\Browy\app\node.exe" "$env:LOCALAPPDATA\Browy\app\dist\cli-bin.js" --version
```
</Aside>

</TabItem>
<TabItem label="macOS" icon="seti:apple">

打开终端运行：

```bash
curl -fsSL https://github.com/BrowyHQ/browy/releases/latest/download/install.sh | bash
```

安装脚本会：

<Steps>
1. 检测你的架构（Apple Silicon 或 Intel）并下载对应的 tar 包（约 75 MB）
2. 把本地主机安装到 `~/.browy/app/`
3. 在 Chrome / Edge / Brave 注册 `com.browy.host`（同时预批准两种扩展 ID）
4. 把扩展的未打包版本放到 `~/Downloads/Browy-Extension/`
</Steps>

<Aside type="tip" title="✓ 确认">
回到侧边栏。几秒钟内它会自己检测到后端并进入聊天界面（如果没有，关掉侧边栏再重新打开）。还是不行？确认主机已经装好：

```bash
~/.browy/app/node ~/.browy/app/dist/cli-bin.js --version
```
</Aside>

</TabItem>
<TabItem label="Linux" icon="linux">

打开终端运行：

```bash
curl -fsSL https://github.com/BrowyHQ/browy/releases/latest/download/install.sh | bash
```

安装脚本会：

<Steps>
1. 检测你的架构（`x86_64` 或 `aarch64`）并下载对应的 tar 包（约 82 MB）
2. 把本地主机安装到 `~/.browy/app/`
3. 在 Chrome / Edge / Brave 注册 `com.browy.host`（写入 `~/.config/<browser>/NativeMessagingHosts/`，同时预批准两种扩展 ID）
4. 把扩展的未打包版本放到 `~/Downloads/Browy-Extension/`
</Steps>

<Aside type="tip" title="✓ 确认">
回到侧边栏。几秒钟内它会自己检测到后端并进入聊天界面（如果没有，关掉侧边栏再重新打开）。还是不行？确认主机已经装好：

```bash
~/.browy/app/node ~/.browy/app/dist/cli-bin.js --version
```
</Aside>

</TabItem>
</Tabs>

## 第三步：登录 Copilot

点击 Browy 图标打开侧边栏。第一次使用时，Browy 会提示你登录。

<figure class="browy-frame">
  <Image src={panelSignin} alt="Browy 侧边栏显示 'Sign in to GitHub Copilot' 按钮" />
  <figcaption>点击 "Sign in to GitHub Copilot"，然后按提示完成 device-flow 授权。</figcaption>
</figure>

会有一个终端窗口打开，里面有 GitHub Copilot 的 **device-flow** 链接。
把验证码粘贴到链接里、在浏览器里授权 Browy，终端会自动关闭。

<Aside type="tip" title="✓ 确认">
在任意一个标签页里输入"这个页面的标题是什么"。你应该看到一次
`snapshot` 工具调用，然后是流式回复。
</Aside>

完成了。试试[你的第一次对话](/zh-cn/first-chat/)，里面有五个具体示例。

## 更新

再次运行安装脚本即可。它会检测到已有安装并就地升级，聊天记录和设置都会保留。当 Web Store 把扩展更新到比你的后端更新的版本时，侧边栏会显示一条黄色的 **browy backend is out of date** 提示，上面的按钮可以直接复制这条命令。

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

```powershell
irm https://github.com/BrowyHQ/browy/releases/latest/download/install.ps1 | iex
```

</TabItem>
<TabItem label="macOS / Linux" icon="seti:apple">

```bash
curl -fsSL https://github.com/BrowyHQ/browy/releases/latest/download/install.sh | bash
```

</TabItem>
</Tabs>

侧边栏会自动重新连接到新的后端。如果你是以未打包方式加载的扩展，还需要在 `chrome://extensions/` 里**重新加载**它（点 Browy 卡片上的循环 ↻ 图标），才能用上新的扩展文件。从 Web Store 安装的扩展会自动更新。

## 卸载

<Tabs syncKey="os">
<TabItem label="Windows" icon="seti:windows">

<Steps>
1. 在 `chrome://extensions/` 移除扩展
2. 删除 `%LOCALAPPDATA%\Browy\`、`%USERPROFILE%\.browy\` 和 `%USERPROFILE%\.browseragent\`（主机日志）
3. 删除原生消息主机注册：
   `%LOCALAPPDATA%\Google\Chrome\User Data\NativeMessagingHosts\com.browy.host.json`
   （Edge 和 Brave 下也有同名文件）
</Steps>

</TabItem>
<TabItem label="macOS" icon="seti:apple">

<Steps>
1. 在 `chrome://extensions/` 移除扩展
2. 运行内置卸载脚本，然后删除安装目录：
   ```bash
   ~/.browy/app/uninstall.sh && rm -rf ~/.browy ~/.browseragent ~/Downloads/Browy-Extension
   ```
3. 卸载脚本会清理
   `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/`
   下的清单文件（Edge 和 Brave 也类似）。
</Steps>

</TabItem>
<TabItem label="Linux" icon="linux">

<Steps>
1. 在 `chrome://extensions/` 移除扩展
2. 运行内置卸载脚本，然后删除安装目录：
   ```bash
   ~/.browy/app/uninstall.sh && rm -rf ~/.browy ~/.browseragent ~/Downloads/Browy-Extension
   ```
3. 卸载脚本会清理 `~/.config/google-chrome/NativeMessagingHosts/`
   下的清单文件（Edge 和 Brave 也类似）。
</Steps>

</TabItem>
</Tabs>

<Aside type="note" title="你的对话记录">
对话记录保存在 GitHub Copilot SDK 的存储里（`~/.copilot/` 下），和其他
Copilot CLI 会话放在一起，所以卸载不会删除它们。如果想删掉，请在卸载之前
先从侧边栏的历史记录里删除这些对话。
</Aside>

## 故障排查

<Aside type="caution" title="“browy backend is out of date”">
Web Store 已经更新了扩展，但你电脑上的后端比它旧，所以一些新功能（比如删除聊天）用不了。点击提示条里的 **copy update command**，粘贴到 PowerShell 或终端里运行，侧边栏会自动重新连接。参见[更新](#更新)。
</Aside>

<Aside type="caution" title="“Host disconnected, reconnecting…”">
侧边栏连不上本地主机。常见原因：本地主机没有装成功（重新运行安装脚本）；浏览器在主机注册之前就已经打开（重启浏览器）；或者杀毒软件 / 终端防护把内置的 `node` 隔离了（把安装目录加入白名单：Windows 上是 `%LOCALAPPDATA%\Browy\`，macOS 和 Linux 上是 `~/.browy/`）。
</Aside>

<Aside type="caution" title="“Host unreachable, reinstall →”">
重连尝试已经放弃。点击提示条里的 **Reinstall host**，它指向你第一次安装时用的同一条安装命令（Windows 上是 `install.ps1`，macOS / Linux 上是 `install.sh`）。重新安装会保留你的聊天记录和设置。
</Aside>

<Aside type="note" title="“Browy started debugging this browser”">
会话进行时，Chrome 会显示它标准的调试提示条。Browy 就是通过这种方式读取和操作页面的。关闭这个提示条会断开智能体。完整说明见[权限 → debugger](/zh-cn/permissions/)。
</Aside>
